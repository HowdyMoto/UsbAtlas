First public release of USB Atlas, a native Windows USB topology explorer.

## Download and run

Download **UsbAtlas-1.0.0-win-x64.zip**, extract the entire archive, and open **UsbAtlas.exe**. For Windows 10/11 x64. Includes .NET 10 Desktop Runtime 10.0.11; no separate runtime installation is needed. No installer or driver installation is required.

## Features

- Interactive USB topology with compact cards, vertical/horizontal layouts, zoom, pan, and collapsible hubs.
- Search, issue navigation, and a resizable device inspector.
- Reported controller/root-hub protocol support and negotiated device link speeds.
- Better device names using USB descriptors, Windows names, and an offline USB ID database.
- Saved custom labels, with detected hardware identity retained.
- Refresh/F5 progress feedback, automatic refresh, and JSON export.
- Light/dark themes and sample hardware for exploration.

## Measurement limits

Link speeds are negotiated signaling rates, not measured traffic or available bandwidth. Power information is device-declared maximum draw, not measured consumption. Supply budgets, USB Power Delivery contracts, and cable ratings remain unknown. USB ID matches can identify chip vendors rather than retail brands.

Scans stay local and do not reconfigure devices. Exported snapshots can contain device serial numbers and custom labels.
