USB Atlas 1.7.0 lets you correct a socket that Windows describes wrongly. Some boards' firmware flags a connection with no socket, such as an onboard hub's link or a header the case doesn't use, as a USB-C socket; you can now say what it really is.

## What's new

- **Socket type**: under Port in Properties, beside **Socket speed**, choose **USB-A**, **USB-C** or **Internal: no socket**, or leave it **As detected**. Like the socket speed, it's saved with port names and covers both halves of a USB 3 socket.
  - The socket is drawn as you set it: a pill for USB-C, a rectangle for USB-A, or a plain built-in slot.
  - Detection details gives both your setting and what Windows reported, such as "You set this socket's connector to built in, with no socket to plug into; Windows reports a USB-C socket."
  - A socket set to USB-A or Internal no longer lists USB4, DisplayPort or Power Delivery.
  - The firmware's own description is kept: `atlascli check` and `map` still check what the firmware says.
  - Found on an MSI B550 board whose firmware flags three sockets as USB-C, where only one USB-C socket can be reached (#57).

### Command line

- `show` adds `socket.connectorSet` for a socket whose type you set.

## Download and run

Download **UsbAtlas-1.7.0-win-x64.zip**, extract the entire archive, and open **UsbAtlas.exe**. The command line, **atlascli.exe**, is in the same folder. For Windows 10/11 x64. Includes the .NET 10 Desktop Runtime; no separate runtime installation is needed. The command line is also available for Linux as **atlascli-1.7.0-linux-x64.tar.gz** and **atlascli-1.7.0-linux-arm64.tar.gz**; it hasn't yet run on real Linux hardware.

This build is unsigned: Windows SmartScreen will warn on first run, and some organizations block unsigned executables. A SHA-256 checksum is included; see **Download** in the README for how to verify it.

The packaged executable passed its self-tests and the offscreen WPF UI checks in light and dark themes, at default, compact and wide window sizes and in both layouts. The packaged `atlascli` passed its self-test, which runs every command against the sample topology and checks the MCP protocol.
