USB Atlas 1.1.0 adds a traditional device tree, redraws hub connections so they never cross, and updates itself when you plug in or unplug a device.

## What's new

- Collapsible, resizable device tree on the left, with controllers, hubs, and devices in port order.
- Synchronized selection between the tree, topology graph, and inspector. Selecting a tree entry brings its card into view and briefly rings it; selecting on the graph highlights and scrolls to the tree entry.
- Search applies to both views; tree expansion state is retained when redrawing the graph.
- Every logical port is drawn as a numbered socket along the hub's bottom edge in vertical layouts and right edge in horizontal layouts. Occupied sockets are outlined and empty ones faded, replacing the empty-port summary and the Empty slots toggle. Device connections start at their own ports.
- Connections never cross. Devices sit in port order and connections fan out from their ports with rounded corners. When space is short, groups of end devices become compact staircases instead of wrapping onto new rows.
- Automatic rescans when USB devices are connected or disconnected. The status bar names what changed, and newly connected devices briefly ring.

## Download and run

Download **UsbAtlas-1.1.0-win-x64.zip**, extract the entire archive, and open **UsbAtlas.exe**. For Windows 10/11 x64. Includes .NET 10 Desktop Runtime 10.0.11; no separate runtime installation is needed.

The packaged executable passed self-tests and offscreen WPF UI checks, including tree selection and sync, filtering, collapse/restore, both graph orientations, crossing-free routing on crowded hubs, device-change rescans, and compact layouts. Light and dark renders were visually checked. A SHA-256 checksum is included.
