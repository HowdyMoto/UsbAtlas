USB Atlas 1.7.1 makes the download easy to find your way around. The folder used to hold over 400 files, mostly .NET runtime DLLs, with **UsbAtlas.exe** somewhere among them; now it holds a handful.

## What's new

- **UsbAtlas.exe** and **atlascli.exe** are each a single file with the .NET runtime inside. Beside them are five small DLLs WPF needs and the license and notice files: 11 items instead of over 400.
- **atlascli.exe** runs on its own, so you can copy it anywhere, such as a folder on your PATH or a tools folder an MCP configuration points at, without the rest of the app.
- The download is larger, about 88 MB instead of 66 MB, since the app and the command line each carry their own runtime.
- Nothing else changes: the app and the command line work as in 1.7.0.

## Download and run

Download **UsbAtlas-1.7.1-win-x64.zip**, extract the entire archive, and open **UsbAtlas.exe**. The command line, **atlascli.exe**, is in the same folder. For Windows 10/11 x64. Includes the .NET 10 Desktop Runtime; no separate runtime installation is needed. The command line is also available for Linux as **atlascli-1.7.1-linux-x64.tar.gz** and **atlascli-1.7.1-linux-arm64.tar.gz**; it hasn't yet run on real Linux hardware.

This build is unsigned: Windows SmartScreen will warn on first run, and some organizations block unsigned executables. A SHA-256 checksum is included; see **Download** in the README for how to verify it.

The packaged executable passed its self-tests and the offscreen WPF UI checks in light and dark themes, at default, compact and wide window sizes and in both layouts. The packaged `atlascli` passed its self-test, which runs every command against the sample topology and checks the MCP protocol.
