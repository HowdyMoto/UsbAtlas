USB Atlas 1.10.0 makes multi-chip hubs read as one physical product, with each chip visibly connected to its own ports.

## What's new

- **One card per hub unit.** Hub chips connected through firmware-reported built-in ports share one card, with the product name and chip/port counts. Ordinary plugged-in hubs stay separate.
- **Chips and ports grouped together.** Each chip sits beside its own sockets, joined by a short line and bracket. Subtle backgrounds group the sections; hovering a chip, port, or attached device highlights the matching group. Internal arrows show real chains and branches.
- **Per-chip details stay available.** Click a chip to inspect its links, bandwidth and issues. Fault badges identify the affected internal chip. Both USB links in the upstream cable remain visible.
- **Clearer Properties.** A compact connection overview leads, with the full parent-port, connection, device, socket and downstream details available below. Eligible devices offer a confirmed, administrator-approved Windows device restart.
- **Activity feed.** The app records connection and issue changes, and power-source and battery events. The CLI watch also reports power and adapter status where Windows exposes it.
- **Automatic CLI logs.** Watch and trace run until Ctrl+C by default and save their output automatically.
- **Calmer connection lines and meters.** Idle links are faint and solid; patterns mark faults. Bandwidth meters state whether the reservation fits, and badges use plain-language descriptions.

## Download and run

Download **UsbAtlas-1.10.0-win-x64.zip**, extract the entire archive, and open **UsbAtlas.exe**. **atlascli.exe** is included beside it. For Windows 10/11 x64, with the .NET 10 runtime included.

The CLI is also available as **atlascli-1.10.0-linux-x64.tar.gz** and **atlascli-1.10.0-linux-arm64.tar.gz**. Linux scanning still awaits verification on real Linux hardware.

This build is unsigned, like the previous release. Windows SmartScreen may warn on first run. Verify downloads using **SHA256SUMS.txt**.

## Validation

The packaged Windows app passed its self-tests and off-screen UI verification at default, compact, vertical, wide and dark settings. The packaged CLI passed its self-tests. Hub fixtures cover chip/socket alignment, brackets, hover and selection, chains and branches, search, folding, missing USB 3 sides and external wire routing. Linux archives are cross-built on Windows.
