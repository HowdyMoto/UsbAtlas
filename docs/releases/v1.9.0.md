USB Atlas 1.9.0 says when a port can't charge a device, shows which drivers set a device apart, and always opens on a map you can read.

## What's new

- **Charging.** A device that needs more power than its port can give now says so. A Quest headset on a USB-A port, for example, shows “Charges slowly here”. Properties has new Charging and Battery rows. Phones and headsets that share files report their battery, and a battery that keeps falling while plugged in is a warning: “Battery draining while plugged in”.
- **Drivers.** Properties has a Driver section in place of the generic driver every device used to show. Status gives the device's problem code and what it means. Driver says whether Windows' own drivers run it, or a maker's driver with its date, or WinUSB, which means an app drives it directly. Filters lists filter drivers that other programs put under the device, such as webcam effects, antivirus or virtual machine passthrough.
- **A readable first look.** The app no longer opens on cards shrunk too small to read. When the whole map doesn't fit at a readable size, it opens at one, starting from the first host, and you scroll to the rest. **Fit all** still shows everything.
- **A narrower vertical layout.** When a hub has three or more devices with nothing plugged into them, they stack into two staggered rows instead of one long row.
- **Hub stages keep your layout.** Snapping a hub stage still switches to the vertical layout, but it no longer makes every later start open in vertical. Only the layout buttons change that. If the app has opened in vertical since you snapped a stage, click the horizontal layout button once.
- **Sleep and wake.** Devices that drop out while the computer sleeps are no longer counted as unstable connections. `atlascli watch` reports devices that come back late after waking, and lists any that are still missing.
- **The command line reports drivers.** `tree` names makers' drivers and other programs' filters. `find` searches drivers, makers and “filter driver”. `diff` reports drivers installed, updated or removed, and filters added or removed.
- Properties' section headings are larger, on a tinted band, so the panel no longer reads as a wall of text.
- A storage enclosure stuck at USB 2 speed explains that an empty enclosure may wait for a drive before it brings up its USB 3 link.

## Download and run

Download **UsbAtlas-1.9.0-win-x64.zip**, extract the entire archive, and open **UsbAtlas.exe**. The command line, **atlascli.exe**, is in the same folder. For Windows 10/11 x64. Includes the .NET 10 Desktop Runtime; no separate runtime installation is needed. The command line is also available for Linux as **atlascli-1.9.0-linux-x64.tar.gz** and **atlascli-1.9.0-linux-arm64.tar.gz**; it hasn't yet run on real Linux hardware.

This build is unsigned: Windows SmartScreen will warn on first run, and some organizations block unsigned executables. SHA-256 checksums are in **SHA256SUMS.txt**; see **Download** in the README for how to verify them.

The packaged app passed its self-tests and the offscreen WPF UI checks at default, compact, vertical, wide and dark settings. The packaged `atlascli` passed its self-test, which runs every command against the sample topology and checks the MCP protocol.
