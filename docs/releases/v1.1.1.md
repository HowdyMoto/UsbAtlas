USB Atlas 1.1.1 makes device search easier to recognize and read.

## Fixes

- Added a magnifying glass inside the search box, visible before and during typing and matched to the current theme.
- Fixed vertically shifted and clipped search text. Typed queries and the placeholder are centered, with room for the icon.
- Removed duplicate padding from the shared textbox template.

## Download and run

Download **UsbAtlas-1.1.1-win-x64.zip**, extract the entire archive, and open **UsbAtlas.exe**. For Windows 10/11 x64. Includes .NET 10 Desktop Runtime 10.0.11; no separate runtime installation is needed.

The packaged executable passed self-tests and compact offscreen WPF UI checks in light and dark themes, including a regression check for search text visibility, alignment, and icon spacing. Search box renders were visually checked in both themes. A SHA-256 checksum is included.
